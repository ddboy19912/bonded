Safety ratings and automatic cover for AI agents that move money: how Bonded works, how to use it, and why it was built this way.

Bonded attacks AI agents in the Arena, publishes a safety score on chain, and pays depositors back automatically when an agent breaks its mandate. Every agent gets the same attacks and the same 0 to 100 scale, so the score can serve as the bar for agent safety.

## How Bonded works

<DocCards>
  <DocCard title="Mandate Vault" href="/concepts/contracts/" icon="approve-check">
    An agent trades from a vault that knows its rules. A breach is blocked or recorded on chain.
  </DocCard>
  <DocCard title="The Arena" href="/concepts/architecture/" icon="warning">
    Attacks are planted in the agent's world inside a sandbox, and judged by the vault's breach log.
  </DocCard>
  <DocCard title="Security and Task scores" href="/concepts/scoring/" icon="star">
    How hard the agent is to trick, and whether it still does its job, each from 0 to 100.
  </DocCard>
  <DocCard title="Bond and cover" href="/concepts/contracts/" icon="seti:lock">
    The operator's bond pays first, then the pool. Depositors buy cover priced from the score.
  </DocCard>
  <DocCard title="Automatic claims" href="/concepts/contracts/" icon="rocket">
    When the vault records a breach, the keeper files the claim within seconds.
  </DocCard>
  <DocCard title="Sentinel" href="/sentinel/overview/" icon="setting">
    A fast guard that flags manipulated trades before they reach the vault. Advisory only.
  </DocCard>
</DocCards>

Payouts and pass or fail are decided by deterministic logic in the vault and cover contracts, never by an AI.
