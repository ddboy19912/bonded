Provider logos used to label models on the Bonded Index charts.

From LobeHub Icons (`@lobehub/icons-static-svg` 1.95.1, MIT licence, https://github.com/lobehub/lobe-icons): `meta-color.svg`, `deepseek-color.svg`, `zai.svg` (fill set to black, since an `<img>` has no current colour), `qwen-color.svg` and `claude-color.svg` (saved as `claude.svg`, for Anthropic's models). The marks belong to their companies and are used only to name their models.
