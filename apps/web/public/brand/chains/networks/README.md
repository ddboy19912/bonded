# Network logos

Shown beside a wallet's network in the header's wallet menu (`src/lib/chain-logos.ts` maps chain ids to
these files).

- Every logo except `robinhood.svg` is from RainbowKit 2.2.11 (`dist/*.js` chain icons), MIT licence,
  copyright (c) 2024 Rainbow.
- `robinhood.svg` is the Robinhood mark from simple-icons (CC0-1.0, see `../../integrations/README.md`)
  on a lime disc.
